Here is the complete API for your Project AU LISP VM, combining the built-in host functions and the available LISP special forms/functions derived from your code:

### **Core LISP Special Forms & Built-in Constructs**

* `(quote expr)` (or `'expr`) - Returns the expression literally without evaluating it.


* `(if condition thenExpr elseExpr)` - Conditional branch that evaluates `thenExpr` if the condition is true, otherwise `elseExpr`.


* `(and expr1 expr2 ...)` - Logical short-circuit AND evaluation.


* `(or expr1 expr2 ...)` - Logical short-circuit OR evaluation.


* `(not expr)` - Logical negation.


* `(while conditionExpr bodyExpr1 bodyExpr2 ...)` - Loop that repeatedly evaluates body expressions while the condition is true.


* `(define symbol expr)` - Binds a value to a symbol in the environment.


* `(set! symbol expr)` - Updates an existing bound symbol with a new value.


* `(print arg1 arg2 ...)` - Outputs values to the output console box.


* `(lambda params body)` - Creates an anonymous function.


* `(begin expr1 expr2 ...)` - Sequentially evaluates multiple expressions and returns the result of the last one.



### **Arithmetic & Comparison Functions**

* `(+ a b)` - Addition


* `(- a b)` - Subtraction


* `(* a b)` - Multiplication


* `(/ a b)` - Division


* `(< a b)` - Less than


* `(> a b)` - Greater than


* `(<= a b)` - Less than or equal to


* `(>= a b)` - Greater than or equal to


* `(= a b)` - Equality


* `(/= a b)` - Inequality


* `(mod a b)` - Modulus / remainder


* `(abs a)` - Absolute value



### **List Operations & Type Checking**

* `(atom x)` - Returns true if `x` is an atom (not a list/array)


* `(eq a b)` - Strict equality check


* `(car x)` - Returns the first element of a list


* `(cdr x)` - Returns the rest of the list after the first element


* `(cons x y)` - Constructs a new list by prepending `x` to `y`


### **Graphics & Canvas (128x128px, 16-color palette)**

* `(cls c)` - Clear canvas with palette color index `c` (defaults to 0)


* `(pset x y c)` - Set a single pixel at `(x, y)` to color index `c`

* `(line x0 y0 x1 y1 c)` - Draw a Bresenham line from `(x0, y0)` to `(x1, y1)` using color index `c`

* `(rect x y w h c)` - Draw an outline rectangle at `(x, y)` with width `w`, height `h`, and color index `c`

* `(frect x y w h c)` - Draw a filled rectangle


* `(circ x y r c)` - Draw a circle outline centered at `(x, y)` with radius `r` and color index `c`

* `(fcirc x y r c)` - Draw a filled circle


* `(pget x y)` - Get the palette color index of the pixel at `(x, y)`


### **Utilities, Input & Time**

* `(rand n)` - Generate a random integer from `0` up to `n - 1`

* `(time)` - Get current epoch timestamp in milliseconds (`Date.now()`)


* `(clock)` - Get high-resolution performance timer (`performance.now()`)


* `(mouse-x)` - Get the current X coordinate of the mouse/pointer on the canvas


* `(mouse-y)` - Get the current Y coordinate of the mouse/pointer on the canvas


* `(mouse-btn buttonIndex)` - Check if a specific mouse button is pressed (defaults to `0` for left click)


* `(key? k)` - Check if a keyboard key (by string name or code like `"space"`, `"arrowup"`) is currently held down



### **Special Lifecycle Hooks**

* `(setup)` - Optional user function run once when execution starts


* `(update dt)` - Optional user function run every animation frame, passing delta time `dt` in seconds
